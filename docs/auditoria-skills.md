## Remotion (paquete npm, 25/10/2026)

Instalado `remotion`, `@remotion/cli`, `@remotion/renderer` y `@remotion/bundler` 4.0.538 (fijos, iguales entre sí) con React 19.2.0. Juani lo usa como persona individual, bajo la licencia gratis de Remotion. Chequeo del código instalado: el aviso de uso a `remotion.pro` (`@remotion/licensing`) **solo se manda si se le pasa `licenseKey`** (incluso `"free-license"` lo manda); sin clave no sale nada, y en este repo nunca se pasa. Otra red: la descarga de Chrome Headless Shell la primera vez (si no se le da un Chrome con `REMOTION_CHROME`) y el aviso de versión nueva contra registry.npmjs.org. `npm audit` marca zod 4.5.4 (consumo de memoria al validar colecciones enormes): Remotion exige esa versión exacta y acá solo valida nuestras propias props, así que se deja.

Paquetes de motion (25/10/2026, con `npx remotion add`): `@remotion/captions`, `@remotion/gsap`, `@remotion/three` y `@remotion/lottie` 4.0.538; `gsap` 3.15.0, `@react-three/fiber` 9.8.2 y `@types/three` 0.160.0, todos con versión fija. Ninguno tiene scripts de instalación. `three` se dejó en 0.160.0 porque lo usa el editor. `remotion-dev/skills` sigue en 6c67adc: no hay skills nuevas para sumar.
