# Sala de Montaje

Fábrica de edición de video de Juani: un editor por código (artifact de claude.ai) más las herramientas que usa
Claude Code en la nube para editar a fondo. Todo el contexto para trabajar está en `CLAUDE.md`.

```
npm run build   # arma dist/sala.html
npm test        # pruebas en Chromium sin pantalla (necesitan el video de prueba en .media/)
```
